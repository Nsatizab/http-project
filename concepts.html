Key Concepts

Seven terms behind an everyday click.

Home Behind Every Click HTTP Evolution Key Concepts References About

1. Request: asking for something

A request is a message a client sends to a server. It identifies a resource and the action the client wants to perform.

For instance, your browser sends a request when it asks a server for an image.

2. Response:answering the request

A response is the message a server returns to the client. It has a status code, headers and sometimes a body with the item you requested.

For instance, the server can return an image or report that the image was not found.

3. Method: choosing the action

A method tells the server what action the client wants to perform on a resource.

GET requests a resource. POST asks the server to process submitted content, such as form information.

4. Status code: reporting the result

A status code is a three-digit number in a response. It tells the client what happened to its request.

  • 200 OK: the request succeeded.
  • 404 Not Found: the resource was not found.
  • 500 Internal Server Error: the server encountered a problem

5. Header: adding useful details

Headers carry extra information in requests and responses. They help explain how to handle a message.

For instance, Content-Type identifies the type of content being sent, such as HTML or an image. Cache-control provides rules for caching.

6. Cookie: connecting separate visits

A cookie is a small piece of data stored by the browser. The browser can send it back to the server with later requests.

For instance, a cookie can hold a session indentifier that helps a shopping website recognize your carts. HTTP itself remains stateless.

7. Cache: reusing a saved copy

A cache stores copies of resources for possible reuse. When caching rules allow it, a browser can reuse a saved resource instead of downloading it again.

For instance, a saved website logo can reduce repeated downloads as you browse different pages.
