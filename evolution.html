Same job, more traffic

HTTP is used by both a simple page and a busy online business. As sites add more images, scripts and other resources browsers had more to ask for. HTTP developed to be able to handle those transfers more effectively.

What changed with each version?

How HTTP handles a growing web
Version Main change Why it matters
HTTP/1.0 Usually opened a new connection for each request. Loading many resources meant opening many connections.
HTTP/1.1 Reuses connections by default. Several requests can use the same connection.
HTTP/2 Multiplexes requests and responses over one connection. Multiple exchanges can progress at the same time.
HTTP/3 Uses QUIC to carry HTTP exchanges. A lost packet on one stream does not block other streams.

A faster exchange still needs clear meaning

HTTP versions modify how messages travel, but methods, status codes and headers still describe what those messages imply. A GET request still requests a resource, and a 404 answer still says it was not found.
