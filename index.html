You click. A conversation begins.

Opening a website is like one easy task. Behind the screen, your browser asks for data and a server responds. HTTP or Hypertext transfer protocols and dictates the rules for such transaction.

This page explains how HTTP works, how it has evolved, and how cookies and caching help make ordinary web experiences possible. It asks which problem each change solved.
